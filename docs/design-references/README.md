# Asset design references

These images are visual targets used when shaping original PitchLens assets.
They are not product screenshots or proof that a feature is implemented.
The application loads its authored assets from `public/models` and constructs
the pitch, ball and goal geometry in Three.js; see [3D rendering](../3d-rendering.md).

| Reference | Purpose |
| --- | --- |
| [Player](player.png) | Footballer silhouette, kit and faceted style |
| [Goalkeeper](goalkeeper.png) | Goalkeeper proportions, sleeves and gloves |
| [Corner flag](corner-flag.png) | Pole and cloth proportions |
| [Ball](ball.png) | Football panel shape and appearance |
| [Goal](goal.png) | Goal frame and net appearance |
| [LED board](led-board.png) | Perimeter board design target |

For the current working interface, use the [README screenshots](../screenshots/readme)
and [finished demonstration](../pitchlens-demo-smooth.mp4).
