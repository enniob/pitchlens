# PitchLens demonstration recording

Target length: 1 minute 50 seconds. Record the deployed application functioning
in a desktop browser. This is the recording package, not a completed video.

Unlock AI access before recording so the access code is not shown. Use the
scripted demo for reproducible events, and prepare both audience versions and
the recap beforehand. If a prepared answer is cached, describe it as prepared;
do not imply an instant live model response. When showing a fresh request,
include its loading state and make any edited wait clear.

## Screen sequence and narration

| Time | Screen | Narration |
| --- | --- | --- |
| 0:00–0:12 | PitchLens header, synthetic label, start demo | Football statistics tell us what happened. PitchLens helps explain why a moment matters, using evidence you can replay beside a synthetic match. |
| 0:12–0:28 | Turnover, passing sequence, shot and goal; Tactics numbers | These teams, players and events are fictional. As playback advances, recorded events become current statistics. The simulator is seeded, so the same settings reproduce the same match. |
| 0:28–0:44 | Turnover-to-shot pattern and its supporting events | Here, a turnover leads to three completed passes and a shot. The sequence and its duration are calculated in code. We describe what is recorded, without inventing player intent or defensive pressure. |
| 0:44–1:07 | AI explanation, switch audience at the same moment, expand facts | Microsoft Foundry turns that evidence into an account for a casual fan or an analyst. Both use the same evidence. Factual claims are built in code; the model selects them and writes the explanation. Checks and a separate verifier review the wording. |
| 1:07–1:23 | Citation replay; rewind before goal; restore explanation at cutoff | Every claim links to an event or position snapshot. Replay takes us back to that evidence. Seeking earlier hides later insights, and the model's tools cannot access events beyond the selected time. |
| 1:23–1:38 | Preferences: favorite team/player; focused moments | Preferences focus the moments and measured patterns on a favorite team or player. Personalization changes what is highlighted, while preserving the underlying match and evidence. |
| 1:38–1:50 | Full-time recap, final score and replay controls | The recap brings together the result and defining moments. PitchLens connects match intelligence to evidence you can inspect. Automated checks reduce mistakes; they do not guarantee every AI claim is true. |
